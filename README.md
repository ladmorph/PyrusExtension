# Pyrus — перенос полей

Расширение для Chrome и Edge: переносит поля между задачами одного шаблона на одном сервере Pyrus и заменяет текст в текущей форме. Работает через интерфейс страницы, без API-токена.

## Установка

1. Скачайте проект или клонируйте репозиторий.
2. Откройте `chrome://extensions` или `edge://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное» и выберите папку `PyrusExtension`.

После обновления файлов перезагрузите расширение на той же странице и обновите открытые вкладки Pyrus. Для работы расширения npm-зависимости не нужны.

## Перенос полей

1. Откройте исходную задачу и раскройте нужные разделы.
2. Нажмите значок расширения → «Сохранить поля этой задачи».
3. Перейдите в черновик того же шаблона → «Заполнить черновик».
4. Дождитесь результата на странице, проверьте значения и сохраните задачу средствами Pyrus.

Не переключайте вкладку до завершения. Исходная задача не изменяется. Расширение не сохраняет и не отправляет задачи автоматически; целевой черновик выбираете вы.

По умолчанию заполненные поля и ячейки защищены, пустые дополняются. Пробелы считаются пустым значением. В частично заполненной таблице сохраняются введённые значения и дополнительные строки, а пустые ячейки дополняются по соответствующей строке источника. Порядок строк должен совпадать: расширение не сопоставляет строки по содержимому.

Для замены заполненных значений включите «Заменять заполненные значения»: пустое значение источника тоже может очистить целевое поле. Автоматическое удаление дополнительных строк таблицы не поддержано. Для переноса отдельных полей откройте «Выборочный перенос» → «Сопоставить поля».

Поля заполняются сверху вниз с ожиданием зависимых полей. Для появления зависимого поля переносите и управляющее поле.

Таблицы прокручиваются в область просмотра с ожиданием загрузки строк и столбцов. Если при сохранении источника показано сообщение о таблицах без прочитанных строк, проверьте их: для непустых таблиц дождитесь загрузки и сохраните поля заново. Заполненные значения в черновике проверяются после загрузки таблицы.

## Предзаполнение по ссылке

Кнопка «Заполнить черновик» сначала пробует штатную ссылку Pyrus, если включена соответствующая настройка, черновик пуст и его адрес содержит `/t#uf` с номером формы. Номера полей читаются из явных атрибутов страницы или модели поля с совпадающим названием. Неподтверждённые номера не угадываются.

Поля передаются как `f123=значение`, ячейки — как `f123:1=значение`, где число после двоеточия — номер строки. Поддержаны простые значения и таблицы, для которых удалось определить все столбцы. Справочники, сотрудники и множественный выбор остаются обычному переносу: видимое название не заменяет внутренний идентификатор записи.

После попытки по ссылке всегда выполняется обычный перенос. Если номера неизвестны, форма уже содержит значения или адрес не подходит, сразу используется обычный перенос. Ожидание подстановки по ссылке ограничено пятью секундами. Настройку можно отключить. Фактическое ускорение зависит от того, как установленная версия Pyrus обрабатывает изменение ссылки; тесты проверяют этот переход на искусственной странице.

В разделе «Подготовить ссылку отдельно» можно собрать ссылку для нового черновика или открыть готовую ссылку, скопированную из Pyrus. Эта операция открывает новую вкладку. Значения входят в саму ссылку; сохранённые исходные поля при этом остаются доступны для обычного переноса.

## Поиск и замена

1. Откройте нужную форму и раскройте разделы и строки таблиц.
2. Во вкладке «Замена» укажите «Найти», «Заменить на» и режим поиска.
3. Нажмите «Найти совпадения» и проверьте список изменений.
4. Нажмите «Применить замену», затем проверьте и сохраните форму в Pyrus.

Оба поля ввода поддерживают несколько строк и отдельную кнопку очистки. Поиск буквальный, с учётом регистра. Режим «Всё значение» требует полного совпадения; «Внутри текста» заменяет все вхождения. Ctrl+Enter запускает поиск совпадений. Пустая замена очищает текст; в списках выбирается только существующий точный вариант, очистка списков не поддержана.

Обрабатываются доступные поля и отрисованные ячейки таблиц. Скрытые и виртуализированные строки не охватываются. Предпросмотр действует 10 минут; после повторного открытия окна или изменения формы выполните поиск заново.

## Возможности и ограничения

- Поддержаны текст, даты, флажки, одиночные списки, справочники, сотрудники, множественный выбор и базовые таблицы. Доступные операции зависят от типа поля; замена множественных полей не поддержана.
- В списках и справочниках выбирается точное совпадение. Неоднозначные варианты и заблокированные поля не заполняются.
- Файлы, сложное форматирование и поля в iframe не поддержаны.
- Автотесты используют искусственный DOM. Работа с реальными формами Pyrus, особенно со списками в таблицах, требует проверки в черновике.

Ход заполнения и причины пропуска показываются прямо на странице. Проверки принятия значений остаются частью переноса. Сбор, запись и экспорт диагностических отчётов отсутствуют.

Сохранённые поля, настройки замены и выбор предзаполнения по ссылке хранятся в `chrome.storage.session` до закрытия браузера. Удалить поля и настройки замены можно кнопками «Удалить сохранённые поля» и «Очистить всё» во вкладке «Замена».

## Разработка

Установите Node.js, затем выполните:

```sh
npm install
npm test
```

`jsdom` используется только для тестов.
