# Pyrus — перенос полей

Расширение для Chrome и Edge: переносит поля между задачами одного шаблона на одном сервере Pyrus и заменяет текст в текущей форме. Работает через интерфейс страницы, без API-токена.

## Установка

1. Скачайте проект или клонируйте репозиторий.
2. Откройте `chrome://extensions` или `edge://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное» и выберите папку `PyrusExtension`.

После обновления файлов перезагрузите расширение на той же странице. Для работы расширения npm-зависимости не нужны.

## Перенос полей

1. Откройте исходную задачу и раскройте нужные разделы.
2. Нажмите значок расширения → «Сохранить поля этой задачи».
3. Перейдите в черновик того же шаблона → «Заполнить черновик».
4. Дождитесь результата на странице, проверьте значения и сохраните задачу средствами Pyrus.

Не переключайте вкладку до завершения. Исходная задача не изменяется. Расширение не сохраняет и не отправляет задачи автоматически; целевой черновик выбираете вы.

По умолчанию заполненные поля защищены. Для их замены включите «Заменять заполненные значения»: пустое значение источника тоже может очистить целевое поле. Для переноса отдельных полей откройте «Выборочный перенос» → «Сопоставить поля».

Поля заполняются сверху вниз с ожиданием зависимых полей. Для появления зависимого поля переносите и управляющее поле.

Таблицы прокручиваются в область просмотра с ожиданием загрузки строк и столбцов. Если при сохранении источника показано сообщение о таблицах без прочитанных строк, проверьте их: для непустых таблиц дождитесь загрузки и сохраните поля заново. Заполненные значения в черновике проверяются после загрузки таблицы.

## Поиск и замена

1. Откройте нужную форму и раскройте разделы и строки таблиц.
2. Во вкладке «Замена» укажите «Найти», «Заменить на» и режим поиска.
3. Нажмите «Найти совпадения» и проверьте список изменений.
4. Нажмите «Применить замену», затем проверьте и сохраните форму в Pyrus.

Поиск буквальный, с учётом регистра. Можно искать значение целиком или все вхождения внутри текста. Пустая замена очищает текст; в списках выбирается только существующий точный вариант, очистка списков не поддержана.

Обрабатываются доступные поля и отрисованные ячейки таблиц. Скрытые и виртуализированные строки не охватываются. Предпросмотр действует 10 минут; после повторного открытия окна или изменения формы выполните поиск заново.

## Возможности и ограничения

- Поддержаны текст, даты, флажки, одиночные списки, справочники, сотрудники, множественный выбор и базовые таблицы. Доступные операции зависят от типа поля; замена множественных полей не поддержана.
- В списках и справочниках выбирается точное совпадение. Неоднозначные варианты и заблокированные поля не заполняются.
- Файлы, сложное форматирование и поля в iframe не поддержаны.
- Автотесты используют искусственный DOM. Работа с реальными формами Pyrus, особенно со списками в таблицах, требует проверки в черновике.

## Если что-то не работает

Откройте «Диагностика и помощь» → «Проверить страницу» → «Скачать отчёт JSON». При описании проблемы укажите тип поля и ожидаемый результат.

Если поле не распознано, скачайте структуру исходной и целевой страницы. Для проблем со списком в таблице используйте «Указать проблемную ячейку»: выберите ячейку, дождитесь проверки, откройте тот же список вручную и скачайте сравнение. Для подробной диагностики доступна запись ручного выбора справочника или ячейки.

Обычный отчёт не содержит значений, названий и идентификаторов полей, HTML и адресов страниц. В записи ручного выбора текст и значения заменяются секретными метками сравнения. Файлы скачиваются вручную и автоматически никуда не отправляются.

Для исследования массового заполнения есть кнопка «Скачать диагностику заполнения». На обычном новом черновике раскройте нужные разделы, нажмите в обычное текстовое поле, не меняя значение, затем откройте расширение и скачайте снимок. Повторите на заполненной встроенной копии: нажмите текстовое поле именно во всплывающем окне перед открытием расширения. Копию отправлять не нужно. Подпишите файлы «обычный черновик» и «встроенная копия». Снимок содержит только сведения об обработчиках, размерах коллекций и выбранном контексте. Названия и значения полей, идентификаторы, адреса и токены не читаются. Проверка не вызывает обработчики и не меняет форму. Наличие обработчика само по себе не подтверждает возможность массового заполнения. В отчёте отдельно указаны причины ограничения проверки. Это исследовательская диагностика; обычное заполнение работает прежним способом.

Сохранённые поля, настройки замены и журнал хранятся в `chrome.storage.session` до закрытия браузера. Удалить их можно кнопками «Удалить сохранённые поля», «Очистить настройки замены» и «Очистить диагностику».

## Разработка

Установите Node.js, затем выполните:

```sh
npm install
npm test
```

`jsdom` используется только для тестов.
